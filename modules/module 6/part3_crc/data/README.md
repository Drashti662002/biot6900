## Sources

- **Score:** PGS Catalog **PGS000148** (CRC63; Jeon J et al., *Gastroenterology* 2018;154:2152-2164, doi:10.1053/j.gastro.2018.02.021). 63 SNPs, weights are per-allele log(OR) from a European-ancestry-only GWAS. Harmonized scoring file, **GRCh37** positions. Published EUR validation AUROC 0.59 (PGS Catalog PPM000450, with age, family history, study and endoscopy history as covariates).
  - One row (none) publishes no `other_allele`; I filled it with whichever of the 1000 Genomes REF/ALT is not the effect allele. Effect alleles and weights are unchanged.
  - One row (rs7229639) publishes **no `effect_allele`** (only `other_allele`). I left it blank, so the notebook's keep/flip/drop rule drops it. The simulated disease still includes this locus (taking the effect allele as the non-`other_allele` one), because the biology is real even when the scoring file is broken.
- **Genotypes:** **1000 Genomes phase 3** (release 20130502, **GRCh37**), biallelic SNPs, read region by region from the EBI FTP with bcftools. Tags matched by chromosome, position and alleles.
- **People:** the same 2,336 samples, super-population labels and ages as the Canvas `meta.csv`.

## How the phenotype was simulated

The professor's recipe from the Canvas README, with the same numbers. Random seed **6900**.

1. For each score (tag) SNP, a hidden **causal** SNP was chosen at random among 1000 Genomes SNPs within ±250 kb with **r² > 0.6 with the tag in EUR** and EUR minor-allele frequency ≥ 5%. Tags with no such neighbour are their own causal: rs704017, rs3217810, rs11064437, rs79900961, rs12603526.
2. Each causal SNP got a true per-allele effect equal to its tag's published weight, signed by the direction of its EUR LD with the tag.
3. Liability = genetic score from the causal SNPs (scaled to SD 1) + 0.35 × (age − 60)/8 + Normal(0, 2.09²) noise.
4. The top 30% of liability across the whole cohort are cases. **The same rule applies to every ancestry.**

I did **not** retune the noise SD for this score; it is the professor's value. Mean r² between tags and their causal SNPs: EUR 0.83, AFR 0.45, EAS 0.76, SAS 0.77, AMR 0.74. Per-tag details in `simulation_log.csv`.

## Limitations

- Causal SNPs are picked from SNPs in LD with each tag **in Europeans**, so by construction the score tags its causal SNPs best in EUR. That is how the portability drop arises here, from real 1000 Genomes LD, and it is also why the drop's size depends on this design.
- PGS000148 weights come from a joint model, so some loci carry several SNPs with opposite-sign weights (e.g. the FADS1/2 SNPs on chr11). Each tag still gets its own causal SNP, so in those loci the simulated causal architecture is more complicated than the real one probably is.
